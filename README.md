# HumanCLI

HumanCLIは、個人的にRustを学習するためのプライベートなプロジェクトです。

「人間の生活をすべてCLIで完結させたら、どうなるのか？」という発想から、人間の行動をコマンドで管理するジョークCLIツールを作ります。

## コマンドのイメージ

以下は構想段階の例です。実装済みの機能を示すものではありません。

```sh
# 出勤する
human_cli -move workplace

# ごはん（たまご）を食べる
human_cli -eat egg
```

移動も食事も、生活のあらゆる行動をCLIから実行する。そんな冗談を題材に、Rustの文法や設計、CLIの実装を学んでいきます。

## AIエージェント向けの方針

このプロジェクトでは、開発者自身が学習のためにコードを書きます。AIエージェントは、明示的に実装を依頼された場合を除き、知識の提供や解説を中心に支援してください。

詳しい方針は[.agent/AGENTS.md](.agent/AGENTS.md)を参照してください。
